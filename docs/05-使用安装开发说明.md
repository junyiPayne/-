# BS系统使用安装开发说明

## 1. 文档说明

本文档详细说明BS系统的安装、配置、开发和部署流程。

## 2. 系统要求

### 2.1 硬件要求
- CPU: Intel Core i5 或同等性能
- 内存: 8GB RAM (推荐16GB)
- 硬盘: 50GB 可用空间

### 2.2 软件要求
- Python 3.9+
- Node.js 18+
- SQLite（默认，无需单独安装）
- Git

## 3. 快速开始

### 3.1 克隆项目

```bash
git clone <repository-url>
cd BS系统
```

### 3.2 后端安装

```bash
# 进入后端目录
cd backend

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

### 3.3 数据库配置

**系统默认使用SQLite数据库**，无需安装或配置MySQL。SQLite是一个轻量级的嵌入式数据库，数据库文件会自动创建在 `backend/instance/bs_system.db`。

**如需使用MySQL**（可选），创建 `backend/.env` 文件：

```env
DB_TYPE=mysql
DB_HOST=localhost
DB_PORT=3306
DB_USER=bs_user
DB_PASSWORD=your_password
DB_NAME=bs_system
FLASK_ENV=development
FLASK_DEBUG=True
SECRET_KEY=your-secret-key-here
JWT_SECRET_KEY=your-jwt-secret-key
```

### 3.4 初始化数据库

**首次运行需要初始化数据库**：

```bash
cd backend
python init_database.py
```

这个脚本会：
1. 创建所有数据表
2. 创建默认角色（管理员、教师、学生）
3. 创建默认管理员账户（用户名：`admin`，密码：`admin123`）

### 3.5 启动后端服务

```bash
cd backend
python run.py
```

后端服务将在 http://localhost:5001 启动（使用5001端口避免与macOS AirPlay冲突）

### 3.6 前端安装

```bash
# 进入前端目录
cd frontend

# 安装依赖（首次运行需要）
npm install
```

**注意**：前端已配置代理，自动将 `/api` 请求转发到后端 `http://localhost:5001`，无需额外配置。

### 3.7 启动前端服务

```bash
npm run serve
```

前端服务将在 http://localhost:8080 启动

### 3.8 访问系统

1. 打开浏览器，访问：`http://localhost:8080`
2. 使用默认账户登录：
   - 用户名：`admin`
   - 密码：`admin123`

### 4.2 后端开发

#### 4.2.1 创建新的数据模型

```python
# app/models/new_model.py
from app import db
from datetime import datetime

class NewModel(db.Model):
    __tablename__ = 'new_model'
    
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(100), nullable=False)
    created_at = db.Column(db.DateTime, default=datetime.utcnow)
    
    def to_dict(self):
        return {
            'id': self.id,
            'name': self.name,
            'created_at': self.created_at.isoformat()
        }
```

#### 4.2.2 创建数据库迁移

```bash
python manage.py db migrate -m "Add new model"
python manage.py db upgrade
```

#### 4.2.3 创建API路由

```python
# app/routes/new_route.py
from flask import Blueprint, request, jsonify
from app.models.new_model import NewModel
from app import db

bp = Blueprint('new', __name__, url_prefix='/api/new')

@bp.route('/', methods=['GET'])
def get_list():
    items = NewModel.query.all()
    return jsonify({
        'code': 200,
        'data': [item.to_dict() for item in items]
    })

@bp.route('/', methods=['POST'])
def create():
    data = request.get_json()
    item = NewModel(**data)
    db.session.add(item)
    db.session.commit()
    return jsonify({
        'code': 200,
        'message': '创建成功',
        'data': item.to_dict()
    })
```

#### 4.2.4 注册路由

```python
# app/__init__.py
from app.routes.new_route import bp as new_bp
app.register_blueprint(new_bp)
```


### 5.3 Nginx配置

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /var/www/bs-system/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # API代理
    location /api {
        proxy_pass http://localhost:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

## 6. 常见问题

### 6.1 数据库连接失败

**问题**: 无法连接到数据库

**解决方案**:
1. **SQLite（默认）**：
   - 检查数据库文件是否存在：`backend/instance/bs_system.db`
   - 如果不存在，运行 `python init_database.py` 初始化数据库
   - 检查文件权限

2. **MySQL（如果配置了）**：
   - 检查MySQL服务是否运行
   - 检查数据库配置是否正确（`.env` 文件）
   - 检查用户权限

```bash
# 检查SQLite数据库文件
ls -l backend/instance/bs_system.db

# 如果使用MySQL，检查MySQL服务
sudo systemctl status mysql
mysql -u bs_user -p bs_system
```

### 6.2 端口被占用

**问题**: 端口5000或8080已被占用

**解决方案**:
```bash
# 查找占用端口的进程
# Windows
netstat -ano | findstr :5000

# macOS/Linux
lsof -ti:5000

# 杀死进程
kill -9 <PID>
```

### 6.3 依赖安装失败

**问题**: npm install 或 pip install 失败

**解决方案**:
```bash
# 清除缓存
npm cache clean --force
pip cache purge

# 使用国内镜像
npm config set registry https://registry.npmmirror.com
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt

# 如果pip install失败，尝试使用虚拟环境
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 6.4 前端无法连接后端API

**问题**: 前端请求返回CORS错误

**解决方案**:
在Flask后端添加CORS支持：

```python
from flask_cors import CORS
CORS(app, resources={r"/api/*": {"origins": "*"}})
```

## 8. 维护和更新

### 8.1 更新依赖

```bash
# 后端
pip install --upgrade -r requirements.txt

# 前端
npm update
```

### 8.2 数据库迁移

**SQLite数据库迁移**：

系统使用SQLite，数据库迁移通过Python脚本完成。如需修改数据库结构：

1. 修改模型文件（`backend/app/models/*.py`）
2. 创建迁移脚本（参考 `backend/migrate_reports_to_single.py`）
3. 运行迁移脚本

**MySQL数据库迁移**（如果使用MySQL）：

```bash
# 生成迁移文件
python manage.py db migrate -m "描述"

# 应用迁移
python manage.py db upgrade

# 回滚迁移
python manage.py db downgrade
```

### 8.3 备份数据库

**SQLite备份**：

```bash
# 备份（直接复制数据库文件）
cp backend/instance/bs_system.db backups/bs_system_backup_$(date +%Y%m%d_%H%M%S).db

# 恢复（替换数据库文件）
cp backups/bs_system_backup_YYYYMMDD_HHMMSS.db backend/instance/bs_system.db
```

**MySQL备份**（如果使用MySQL）：

```bash
# 备份
mysqldump -u bs_user -p bs_system > backup.sql

# 恢复
mysql -u bs_user -p bs_system < backup.sql
```
