# AI编程实验环境配置文档

## 1. 环境概述

本文档详细说明BS系统开发所需的AI编程实验环境配置，包括开发工具、编程环境、依赖包等。

## 2. 硬件要求

### 最低配置
- CPU: Intel Core i5 或同等性能AMD处理器
- 内存: 8GB RAM
- 硬盘: 50GB 可用空间
- 网络: 稳定的互联网连接

### 推荐配置
- CPU: Intel Core i7 或更高
- 内存: 16GB RAM 或更高
- 硬盘: SSD 100GB 可用空间
- 网络: 100Mbps 及以上

## 3. 操作系统要求

支持以下操作系统：
- Windows 10/11 (64位)
- macOS 10.15 或更高版本
- Ubuntu 20.04 LTS 或更高版本
- CentOS 7/8

## 4. 开发工具配置

### 4.1 Python环境配置

#### 4.1.1 安装Python

**Windows:**
```bash
# 下载Python 3.9+安装包
# 访问 https://www.python.org/downloads/
# 安装时勾选 "Add Python to PATH"
```

**macOS:**
```bash
# 使用Homebrew安装
brew install python@3.9

# 或从官网下载安装包
```

**Linux (Ubuntu):**
```bash
sudo apt update
sudo apt install python3.9 python3.9-venv python3.9-dev
```

#### 4.1.2 配置虚拟环境

```bash
# 创建项目目录
mkdir -p ~/BS系统
cd ~/BS系统

# 创建虚拟环境
python3.9 -m venv venv

# 激活虚拟环境
# Windows
venv\Scripts\activate

# macOS/Linux
source venv/bin/activate
```

#### 4.1.3 安装Python依赖

```bash
# 升级pip
pip install --upgrade pip

# 安装项目依赖
pip install -r backend/requirements.txt
```

### 4.2 Node.js环境配置

#### 4.2.1 安装Node.js

**使用nvm安装（推荐）:**
```bash
# macOS/Linux
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install 18
nvm use 18

# Windows
# 下载nvm-windows: https://github.com/coreybutler/nvm-windows/releases
nvm install 18
nvm use 18
```

#### 4.2.2 验证安装

```bash
node -v  # 应显示 v18.x.x
npm -v   # 应显示 9.x.x
```

#### 4.2.3 安装前端依赖

```bash
cd frontend
npm install
```

### 4.3 数据库配置

#### 4.3.1 安装MySQL

**Windows:**
- 下载MySQL安装包：https://dev.mysql.com/downloads/installer/
- 运行安装程序，选择"Developer Default"配置

**macOS:**
```bash
brew install mysql
brew services start mysql
```

**Linux (Ubuntu):**
```bash
sudo apt update
sudo apt install mysql-server
sudo systemctl start mysql
sudo systemctl enable mysql
```

#### 4.3.2 配置MySQL

```bash
# 登录MySQL
mysql -u root -p

# 创建数据库和用户
CREATE DATABASE bs_system CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'bs_user'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON bs_system.* TO 'bs_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

## 7. 环境变量配置

### 7.1 后端环境变量

创建 `backend/.env` 文件：

```env
# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_USER=bs_user
DB_PASSWORD=your_password
DB_NAME=bs_system

# Flask配置
FLASK_ENV=development
FLASK_DEBUG=True

# JWT配置
JWT_SECRET_KEY=your-jwt-secret-key
JWT_EXPIRATION_DELTA=86400
```

## 9. 常见问题解决

### 9.1 Python包安装失败

**问题：** pip安装包时出现SSL错误
**解决：**
```bash
pip install --trusted-host pypi.org --trusted-host pypi.python.org --trusted-host files.pythonhosted.org package_name
```

### 9.2 Node.js依赖安装慢

**问题：** npm install速度慢
**解决：**
```bash
# 使用淘宝镜像
npm config set registry https://registry.npmmirror.com

# 或使用cnpm
npm install -g cnpm --registry=https://registry.npmmirror.com
cnpm install
```

### 9.3 MySQL连接错误

**问题：** Access denied for user
**解决：**
```bash
# 检查用户权限
mysql -u root -p
GRANT ALL PRIVILEGES ON bs_system.* TO 'bs_user'@'localhost';
FLUSH PRIVILEGES;
```

### 9.4 端口被占用

**问题：** 端口5000或8080已被占用
**解决：**
```bash
# Windows
netstat -ano | findstr :5000
taskkill /PID <PID> /F

# macOS/Linux
lsof -ti:5000 | xargs kill -9
```
