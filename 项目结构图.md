## 详细数据流向图

```mermaid
sequenceDiagram
    participant U as 用户
    participant B as 浏览器
    participant N as Nginx
    participant F as 前端Vue
    participant API as API层
    participant FL as Flask后端
    participant R as 路由层
    participant S as 服务层
    participant M as 模型层
    participant DB as MySQL数据库
    participant AI as AI服务
    
    U->>B: 访问系统
    B->>N: HTTP请求
    N->>F: 返回前端静态文件
    F->>B: 渲染页面
    
    U->>F: 用户操作(登录/查询等)
    F->>API: 调用API方法
    API->>N: HTTP请求(带Token)
    N->>FL: 转发API请求
    FL->>R: 路由匹配
    R->>S: 调用服务层
    S->>M: 数据操作
    M->>DB: SQL查询/更新
    DB-->>M: 返回数据
    M-->>S: 返回模型对象
    S->>AI: AI分析请求(如需要)
    AI-->>S: 返回AI结果
    S-->>R: 返回业务结果
    R-->>FL: 返回响应
    FL-->>N: HTTP响应
    N-->>API: 返回数据
    API-->>F: 更新界面
    F-->>U: 显示结果
```

## 认证流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant F as 前端
    participant API as API层
    participant B as 后端
    participant DB as 数据库
    participant JWT as JWT服务
    
    U->>F: 输入用户名密码
    F->>API: 调用登录API
    API->>B: POST /api/auth/login
    B->>DB: 查询用户
    DB-->>B: 返回用户信息
    B->>B: 验证密码
    B->>JWT: 生成Token
    JWT-->>B: 返回Token
    B-->>API: 返回Token和用户信息
    API->>F: 保存Token到localStorage
    F->>F: 更新认证状态
    F-->>U: 跳转到主页
    
    Note over F,API: 后续请求自动携带Token
    U->>F: 访问受保护页面
    F->>API: 请求数据(带Token)
    API->>B: GET /api/xxx<br/>Header: Authorization
    B->>JWT: 验证Token
    JWT-->>B: Token有效
    B->>DB: 查询数据
    DB-->>B: 返回数据
    B-->>API: 返回数据
    API-->>F: 更新界面
```

## 技术栈说明

### 前端技术栈
- **框架**: Vue 3 (Composition API)
- **UI库**: Element Plus
- **路由**: Vue Router
- **状态管理**: Pinia
- **HTTP客户端**: Axios
- **构建工具**: Vue CLI

### 后端技术栈
- **框架**: Flask
- **ORM**: SQLAlchemy
- **数据库迁移**: Flask-Migrate
- **认证**: Flask-JWT-Extended
- **跨域**: Flask-CORS
- **WSGI服务器**: Gunicorn

### 基础设施
- **反向代理**: Nginx
- **容器化**: Docker & Docker Compose
- **数据库**: MySQL 8.0
- **AI服务**: DeepSeek / Qwen API
